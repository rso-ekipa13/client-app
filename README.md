# client-app

The Pretty Good Pigeon app for Android, iOS and the browser, written in Flutter. All encryption happens here: keys are generated on the device, messages and images are encrypted before they are sent, and the local history is stored encrypted.

The web build is served from the cluster as its own container.

Owner: Eva Vidic, with screens from everyone. Status: planned.

## Where this fits

This is one of the repositories of [Pretty Good Pigeon](https://github.com/rso-ekipa13), an end-to-end encrypted messenger built by ekipa 13 for the Cloud Computing course at UL FRI (2026/27). The architecture, plan and decisions live in [docs](https://github.com/rso-ekipa13/docs).

`main` only changes through pull requests; day-to-day work goes to `dev`.
